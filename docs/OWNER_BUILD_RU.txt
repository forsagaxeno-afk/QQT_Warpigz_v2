======================================================================

ЧТО ЭТО
-------
Та же сборка 3.3.21, но без плагина Rosie. Городской сервис (продажа,
разбор, склад, ремонт) делает сторонний SteroidAlfredV2 ("BetterAlfred"),
подбор лута — сторонний LooteerV3. Наши плагины работают с ними через
общие API AlfredTheButlerPlugin / LooteerPlugin.

В архиве 9 папок: WarPigs, WarPug, Batmobile, ArkhamAsylum,
HelltideRevamped, HordeDev, Reaper, WonderCity, SilentRaven.

Исправлено под SteroidAlfred (по сравнению с 3.3.21):
- Steroid "завис" (STUCK: склад полон, или "skip cache" с полной сумкой,
  или бесконечные попытки телепорта) — раньше Pit/Хелтайд/Орды/Боссы/
  Андерсити ждали его вечно. Теперь после 300 с непрерывной "работы" без
  завершения пишется одна строка
    "town service busy for 300s without finishing (stash full?) — farming on without it"
  и фарм продолжается без поездок в город (новых запросов нет, пока Steroid
  завис, и минимум 600 с). WarPug и SilentRaven тоже ждут его не больше 300 с.
- Steroid обслуживает только Темис: Arkham с домашним городом Cerrigar
  больше не телепортируется в Cerrigar поверх телепорта Steroid в Темис;
  WonderCity при нужде в городе выходит из Андерсити сразу в Темис.
- Неудачная поездка Steroid (колбэк без аргументов, сумка осталась полной):
  HelltideRevamped после двух таких поездок подряд перестаёт просить новые
  (раньше — поездка каждые ~16 с).

РЕКОМЕНДУЕМЫЕ НАСТРОЙКИ
-----------------------
SteroidAlfred (BetterAlfred):
- Включён; Town = Temis (другого города у него нет).
- "Allow external" — включено (по умолчанию), иначе наши плагины не смогут
  просить поездку.
- "Use keybind" — выключено (по умолчанию): Steroid сам едет в город при
  полной сумке, наши плагины ждут его и продолжают после возврата.
- "Skip cache" — ВЫКЛЮЧИТЬ (с ним полная сумка тайников = STUCK навсегда).
- Склад держать свободным (лимит Steroid 350 предметов; полный склад =
  STUCK). Если Steroid завис: освободить склад, потом его ручной запуск
  (manual keybind) или перезагрузка скриптов.
- Mythic: KEEP (по умолчанию — в склад).
LooteerV3:
- Включён; дистанция подбора 10–15 м (по умолчанию 2 м — активности
  ждут лут только пока LooteerV3 сообщает, что подбирает).
- Behavior: Always (0).
- Auto Loot хоста не нужен (LooteerV3 сам его выключает).
Наши плагины:
- ArkhamAsylum: город Temis (с Cerrigar поездки всё равно идут в Темис).
- SilentRaven: "Auto-fire in town" включить; "Claim trip after" ничего не
  даёт (см. ниже).
- WarPigs / WarPug — как обычно.

ЧЕГО НЕТ ПО СРАВНЕНИЮ С ROSIE
-----------------------------
- Нет правил Rosie для лута: мифики/уники по Item Power, чармы и печати,
  Осколки Первородного Зла, сортировка — только правила Steroid/LooteerV3.
- Нет передачи награды Шёпота SilentRaven на обратном пути поездки и нет
  "claim trip" (поездки в Темис за наградой): награда забирается только
  при визитах в Темис (WarPigs, обелиск Pit, поездка Steroid в Темис при
  стоянии в городе).
- Нет "подбора с ожиданием боя" и прохода к далёкому луту: Arkham у
  глифа, WonderCity у сундука награды и т.п. не идут к дропу сами
  (у LooteerV3 нет evaluate_item) — ждут только пока LooteerV3 подбирает.
- Steroid не видит бой с боссом: его собственная поездка может начаться
  посреди боя (Rosie ждала до 90 с).
- Нет статусов Rosie (stuck / stuck_retry_in / fail_streak / причины
  ожидания), нет её пауз Navigator/Looter, нет отсрочки под TristramLoop,
  нет заглушек Butler/Scavenger для Worldstone.
- Steroid хранит один колбэк: если два плагина просят поездку одновременно,
  колбэк получит только последний (остальные выходят из ожидания по своим
  таймаутам).
- Пока Steroid завис, он держит Batmobile на паузе и LooteerV3 "looting"
  выключенным: активности сами снимают паузу Batmobile при движении, а
  LooteerV3 может не подбирать до перезапуска Steroid/скриптов.
- Нет событий Rosie (поездки/подбор) в шине событий.
