# WarRoom

Read-only dashboard for the QQT_Warpigz_v3 suite. WarRoom collects what the other plugins report and shows it on a web page: what the bot does now, gold, XP, deaths, runs per activity, loot and a timeline, for this session, today and all time. HelltideRevamped's live map and stats are its **Helltide** tab.

WarRoom only watches. It never presses keys, moves the character, starts or stops activities, or changes another plugin's settings. It works under WarPigs (War Plan automation) and with a single activity plugin.

The step-by-step guide is [part 7 of the user guide](../docs/GUIDE_EN.md#7-warroom-dashboard).

## Folder

| Path | What it is |
| --- | --- |
| `main.lua`, `gui.lua`, `core/` | The QQT plugin (collector, menu, data writer). |
| `dashboard/` | The web page (`index.html` plus its scripts and styles). |
| `dashboard/suite_data.js` | Generated: the suite data (`window.SUITE_DATA = {...}`), rewritten every 15 s by default. |
| `dashboard/hr_data.js` | Generated by HelltideRevamped (the Helltide tab) while WarRoom is enabled; its **Web dashboard** option is not needed. |
| `data/` | Generated: persisted today / all-time totals. |
| `server/serve.bat` | Local web server, this PC only: `http://127.0.0.1:8765`. |
| `server/serve-lan.bat` | The same server for phones and tablets on your home network or VPN (needs the access link). |
| `server/serve.ps1` | The server itself (Windows PowerShell 5.1, no installs). |

Generated files are not in the release zip. When you update, you can keep `data/` to keep your all-time totals.

## Open the dashboard

- Double-click `dashboard\index.html`. It opens from the disk; no internet is needed.
- Or run `server\serve.bat` and open `http://127.0.0.1:8765`.
- From a phone: run `server\serve-lan.bat`, allow the Windows firewall prompt for **Private networks** only, and open the `http://<PC address>:8765/t/<key>` link the window prints. For access away from home use a private VPN such as Tailscale; never forward the port on your router.

## Server options

Pass them to `serve.bat` or `serve-lan.bat` (for example `serve.bat -Port 9000`):

| Option | Meaning |
| --- | --- |
| `-Port N` | Port (default 8765, 1024-65535). |
| `-Root "C:\path\to\dashboard"` | Folder to serve (default `..\dashboard` next to the script). |
| `-Lan` | Listen on all IPv4 addresses (what `serve-lan.bat` does). An access key is required for every other device. |
| `-BindAddress 100.x.y.z` | Listen on one address only, for example your Tailscale address. |
| `-NewToken` | Make a new access key; old links stop working. |
| `-Token KEY` | Use your own key (12-64 letters and digits). |
| `-AllowHost name` | Accept an extra host name, for example `mypc.tailnet.ts.net`. |
| `-NoToken` | LAN without a key. Anyone on the network can read the page. Not recommended. |
| `-AllowPublic` | Accept clients outside private / VPN address ranges. Not recommended. |
| `-Quiet` | Do not print one line per request. |

Stop the server with Ctrl+C, by closing its window, or by creating a file `server\stop.flag`.

## Security and privacy

- By default the server listens on 127.0.0.1 only: no firewall prompt, no admin rights.
- It is read-only: GET and HEAD only, no request bodies, only files inside the dashboard folder with web file types (html, js, css, json, images, fonts), no dotfiles, no folder listings, no symbolic links, no `..` or encoded path tricks.
- It checks the `Host` header (blocks DNS rebinding) and, in LAN mode, accepts only private and VPN addresses (10/8, 172.16/12, 192.168/16, 169.254/16, 100.64/10) plus the access key, which the device keeps in an HttpOnly cookie after the first visit. The key is never written to the request log.
- Pages and data are sent with `no-store`, so the browser always shows the latest data, and with a strict Content-Security-Policy (nothing is loaded from other sites).
- The data files contain no character, account or BattleTag name, realm, chat text or file paths. Nothing is sent to the internet.
- `serve.bat` runs PowerShell with `-ExecutionPolicy Bypass` for its own process only; it changes no system setting.
